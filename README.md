# IIUMTawePro Landing

The standalone evergreen landing experience for [IIUMTawePro](https://t.me/iiumtaweprobot).

## Creative direction

**The Living Route** — a continuous journey through schedule, campus navigation, attendance, support, and event operations.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site deploys automatically to GitHub Pages from `main`.
